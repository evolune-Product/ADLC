# Web framework

# fastapi, starlette and python-multipart are bumped here from a security
# audit, not a routine refresh: the pinned 0.115.5/0.41.3/0.0.17 carried live
# CVEs — a Host-header request.url path-spoofing bug in Starlette (fixed by
# 1.3.1) that could desync what a path-keyed middleware sees from what the
# router actually dispatches, and several unauthenticated DoS bugs in
# python-multipart's form parser (quadratic-time parsing, unbounded reads —
# fixed by 0.0.31). Verified, not assumed: the exact versions pinned below are
# what this session's full test suite (397 tests) already ran clean against —
# see requirements.txt's own git history / CLAUDE.md security-audit notes for
# the reasoning, not just the version bump.

# WebSocket / realtime
# Bumped for a real RCE class: socket_app.py configures AsyncRedisManager, so
# this deployment does use Redis as socket.io's inter-server queue — versions
# before 5.14.0 deserialize queue messages with pickle, so a compromised Redis
# (the same instance Celery and the rate limiter also use) could execute
# arbitrary code in the socket.io server process. 5.14.0+ uses JSON instead.

# Token encryption
# Bumped past several CVEs: a statically-linked vulnerable OpenSSL (affects
# every outbound HTTPS call this backend makes — GitHub, GitLab, Jira, Stripe,
# every LLM provider), plus X.509 chain-building bugs. This app's own use of
# `cryptography` is Fernet (symmetric, encryption.py) — the X.509/EC-specific
# CVEs are not a known reachable path here, but the OpenSSL bump alone is
# worth taking for the outbound-TLS surface.

# Simulation agent — headless-Chromium browser driver for persona-driven
# simulated user testing (agents/simulation_agent.py). The pip package alone

# `greenlet>=3.1.1,<4.0.0`, which resolves to greenlet 3.5.5 (a real 3.14
# wheel) instead. Verified by installing both into this checkout's venv.
